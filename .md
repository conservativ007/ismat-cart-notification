# Cart Notification Plugin

WordPress plugin for WooCommerce that displays toast notifications to users with items in their abandoned cart.

## Features

- 🛒 Detects abandoned cart items across all pages
- ⏰ Shows notification 2 hours after cart creation
- 🔔 Configurable notification intervals
- 🎨 Toast notifications using Toastify
- 🔄 Auto-updates cart counters on all pages
- 📱 Works on desktop and mobile

## Requirements

- WordPress 5.0+
- WooCommerce 6.0+
- Toastify library (must be globally enqueued)
- jQuery
